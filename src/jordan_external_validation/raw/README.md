# Restricted Jordan STEPS 2019 participant data

The participant-level Jordan STEPS 2019 files are licensed and are not included in this archive.
Authorized users must obtain the data from the WHO NCD Microdata Repository and place both files here:

- `jor2019.dta`
- `jor2019.csv`

Catalog record: https://extranet.who.int/ncdsmicrodata/index.php/catalog/853

Do not upload, publish or redistribute these participant files. The validation code displays and exports aggregate results only in the journal package workflow.
