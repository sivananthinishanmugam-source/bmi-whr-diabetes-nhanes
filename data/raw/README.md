# NHANES raw data

The fourteen NHANES 2017-2018 XPORT files are public but are not duplicated in this code archive.

From the `nhanes` folder, run:

```bash
python download_sources.py
```

The authoritative filenames, CDC URLs and variable sources are listed in `../DATA_SOURCES.md`.
The complete analysis expects exactly fourteen `.xpt` files in this folder.
